Instructions

  • Level1 - Wireframe rendering on the hi-res canvas
  • Level2 - Wireframe using a custom line-drawing algorithm on a 320×200 pixel grid

Controls

  • W / S - Move forward / backward
  • A / D - Move left / right
  • ← / → - Turn left / right
  • R - Reset scene
